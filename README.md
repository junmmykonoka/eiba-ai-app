# KeibaAI - 完全無料 競馬予想＆出馬表システム

完全無料で運用可能な、機械学習を活用した競馬予想＆出馬表管理システムです。

## 主な機能（フェーズ1：出馬表構築）
- 🏇 **出走馬表ダッシュボード**: JRA公式枠番カラーリング（1〜8枠）、馬番、馬名、性齢、騎手、斤量、調教師、馬体重、オッズ、人気順の完全表示
- 🤖 **AI予想スロット**: 勝率予測スコア（%）および予想印（◎, ◯, ▲, △）の表示スロット
- 📊 **ソート機能**: 馬番順・オッズ人気順・AI予想スコア順のワンクリック切り替え
- 🌐 **出馬表スクレイパー**: netkeibaのレースID（例: `202405021211`）またはURLから出馬表を自動取得・DB保存（レートリミット＆キャッシュ対応）
- 💾 **SQLite DB**: サーバー不要・完全無料のローカルファイルDB

## 起動方法

### 1. 依存ライブラリのインストール
```bash
cd /Users/jun/.gemini/antigravity/scratch/keiba-ai-app
pip install -r requirements.txt
```

### 2. サーバーの起動
```bash
python -m uvicorn backend.app.main:app --reload --port 8000
```

### 3. ブラウザでアクセス
ブラウザで以下のURLを開いてください：
- **Web画面**: `http://localhost:8000/`
- **API ドキュメント**: `http://localhost:8000/docs`
